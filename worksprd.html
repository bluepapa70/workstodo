제품 요구사항 정의서 (PRD): 웹 기반 업무 관리 시스템

본 문서는 노션 스타일의 직관적인 데이터 테이블 UI를 계승하면서, 사용자의 요구사항에 맞춘 자동 정렬 및 완료 업무 월별 그룹화 기능을 제공하는 웹 서비스 구축 사양을 정의합니다.

1. 프로젝트 개요

기존 업무 방식을 고도화하여 등록일 관리 기능을 추가하고, 진행 중인 업무는 상단에, 완료된 업무는 등록일(우선) 혹은 완료일 기준으로 월별 분류하여 하단에 배치하는 정밀한 상태 기반 리스트 뷰를 제공합니다. Cloudflare Pages, Workers, D1 DB 인프라를 활용하여 서버리스 구조로 구축됩니다.

2. 핵심 기능 요구사항 (Functional Requirements)

2.1 데이터 모델 구조

필드명 데이터 타입 필수여부 설명
idTEXT (UUID)필수고유 식별자
titleTEXT필수작업 이름
statusTEXT필수업무 상태 ('진행 중' / '완료')
priorityTEXT필수우선순위 ('높음', '보통', '낮음')
assigneeTEXT선택담당자 이름
descriptionTEXT선택설명 및 비고
created_atTEXT (YYYY-MM-DD)선택[요구사항] 업무 등록일
due_dateTEXT (YYYY-MM-DD)선택마감일
completed_atTEXT (YYYY-MM-DD)선택완료 처리일 (자동)

2.2 리스트 분리 및 정렬 메커니즘

  • 상단 리스트 (진행 중인 업무): status가 '진행 중'인 데이터만 필터링되어 출력됩니다.
  • 하단 리스트 (완료된 업무): status가 '완료'인 데이터를 분리하여 출력합니다.
  • 완료 업무 월별 그룹화 분기 로직:
    1. 데이터에 created_at(등록일)이 존재하면 해당 등록일의 '월(YYYY-MM)'을 그룹 키로 지정합니다.
    2. 만약 created_at이 존재하지 않는 경우(Null/Empty), completed_at(완료일)의 '월(YYYY-MM)'을 차선책 그룹 키로 지정합니다.
    3. 그룹화된 리스트는 최신 월이 상단에 배치되도록 내림차순 정렬됩니다.

3. 기술 스택 아키텍처

  • Frontend: HTML5, CSS3 Custom Properties (다크 테마 디자인), Modern JavaScript (Fetch API)
  • Server/API: Cloudflare Workers (Edge Serverless)
  • Database: Cloudflare D1 (Serverless Relational SQL DB)
  • Deployment: Cloudflare Pages Integration
